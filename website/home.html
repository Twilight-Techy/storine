The document database that is fast, exact and small.

Embed it in a Rust program, run it as a server, or start three servers for a replicated cluster with automatic failover. Written in Rust, with no third-party dependencies.

{{code:python}}
import storine
from decimal import Decimal
from storine import add, gt

db = storine.connect("storine://127.0.0.1:7878")
accounts = db.collection("accounts")
accounts.insert("alice", {"balance": Decimal("100.00")})
accounts.insert("bob", {"balance": Decimal("0.00")})

# Both changes or neither, and never below zero.
with db.transaction() as tx:
    tx.update("accounts", "alice",
              add("balance", Decimal("-10.00"), min=0))
    tx.update("accounts", "bob",
              add("balance", Decimal("10.00")))

accounts.create_index("balance")
rich = accounts.find(gt("balance", Decimal("50")))

Everything a document database needs, in a few megabytes

Each tool is a single file with nothing else to install. The engine, the network server, TLS, the SQL gateway and the web console are all built from the Rust standard library.

Documents, done properly

Collections of JSON-like documents with versions, preconditions, time to live, and atomic writes across collections.

Exact money

Decimals up to 38 digits, mapped to each language's exact decimal type. Server-side add with bounds makes an overdraft impossible.

Queries and indexes

Filters on nested fields, sorting, keyset paging, up to 16 secondary indexes per collection, and exact results every time.

Vector search

Nearest-neighbour queries by cosine similarity, with an HNSW index for large collections and exact scoring of every candidate.

Analytics on the server

Grouped aggregates with exact sums, and an optional columnar copy of a collection for vectorized, parallel scans.

Secure by default

Tokens with roles, TLS for clients and between nodes, encryption at rest with key rotation, and point-in-time recovery.

Fast where it counts

A read takes about 60 nanoseconds in process and 9 microseconds over the network. Against LMDB and RocksDB at equal durability, Storine leads every throughput row.

One engine, three ways to run it

The same storage engine and the same data model, from a library call to a cluster that spreads data across regions.

Embedded

Link storage-core into a Rust program and open a store in a folder. No server, no network.

Server

One process serves clients in eight languages, the SQL gateway and the web console.

{{code:bash}}
storage-server ./data 127.0.0.1:7878
storine-console storine://127.0.0.1:7878

Cluster

Three servers replicate with Raft and fail over on their own. Add --ranges to partition data and place it by region.

{{code:bash}}
storage-server ./n1 10.0.0.1:7878 --node-id 1 \
  --peers 1=10.0.0.1:7878,2=10.0.0.2:7878,3=10.0.0.3:7878
{{/code}}
